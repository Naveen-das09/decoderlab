# Contributing to DecoderLab

Pick an open [GitHub issue](https://github.com/Naveen-das09/decoderlab/issues)
and check related draft pull requests before starting. Capture the researcher
workflow, acceptance criteria, and any scientific, security, or performance
trade-offs in the issue. Use a feature branch or worktree and keep the diff
focused on the agreed task.

Use the [README](README.md) to set up the backend and run the unit suite. Run
the [scientific reference checks](docs/SCIENTIFIC_METHOD.md) for changes to
sampling, decoding, experiment output or chart calculation. Record the exact
commands and results in the draft pull request, along with the evidence needed
to reproduce scientific claims. For UI changes, include desktop and mobile
browser evidence, keyboard accessibility checks, and provenance, units and
uncertainty on scientific charts.

Request human review after the applicable checks pass. The owner approves
merges. Keep simulation execution local until authentication, resource
limits, cancellation and persistence are in place.
